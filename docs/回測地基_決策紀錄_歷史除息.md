## 回測地基決策紀錄(2026-07-29)

### 決定:歷史除權息「放棄回補」,回測採「不含息但公平」

**背景**
回測框架原訂地基有兩塊:universe_membership(survivorship)+ 歷史除權息(含息報酬)。
第一塊已完成。第二塊經測試後放棄,原因如下。

**為什麼放棄回補歷史除息**
1. TWT48U 端點只回傳「當前未來預告」,完全無視歷史日期參數
   (傳 2019 的日期,回的是 2026-07~10 的預告)——跟 STOCK_DAY_ALL 同一種病
2. 「用除息日股價缺口反推股利」測試失敗:2330 在 2023 真實除息 2 次,
   缺口法卻抓出 10 個「除息日」,把普通下跌日誤判為除息,雜訊淹沒訊號,不可用
3. 可靠來源(TWSE 個股股利 API 逐檔查 / 付費資料商)是大工程,不值得為衝 9/7 硬塞

**改採方案:回測明確標注「不含息(price return)」**
- 所有策略與基準「同樣不含息」——A1 沒領息、0050 benchmark 也沒領息,站同一條線,
  相對優劣(誰贏誰輸)不變
- 唯一影響:絕對報酬比真實低約 3-4%/年,但核心問題「策略能否贏 0050」是相對比較,不受影響
- 報告須誠實標注「本回測為不含息報酬,絕對值偏低,相對比較有效」

**關鍵認知**
含息是「錦上添花」,不是「地基」。先前把它列為 Part 1 必做是高估必要性。
真正的地基只有 universe_membership(已完成)。

**若未來要補(列停車場,非急迫)**
- 前向系統(2026起)已有正確含息(corporate_actions + dividend_income),不受此決定影響
- 歷史含息若真要做:逐檔查 TWSE 個股股利 API,或接受付費資料源,屬獨立大工程
